# SnakePress releases

Installers for **SnakePress** — free screenshot, annotation and screen recorder for Windows 10/11.

- Website: https://snakepress.tinhtd.info
- Download the latest version: see **Releases** on the right (`SnakePress_<version>_x64-setup.exe`)
- Report a problem: [Issues](https://github.com/leotrinh/snakepress-release/issues)
- Support / payment: tinhtd.info@gmail.com

The app updates itself from this page (GitHub version). The Microsoft Store version is updated by the Store.
